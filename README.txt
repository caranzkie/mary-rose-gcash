SUMMARY DEFINITIONS:
- Cash-In/Cash-Out amount totals sum the transaction amounts by type.
- Cash-In and Cash-Out fees are calculated and shown separately.
- Total fees = Cash-In fees + Cash-Out fees.
- Cash-In collected = Cash-In amount + Cash-In fees.
- Cash-Out deducted = Cash-Out amount + Cash-Out fees.
- Total transaction amount = Cash-In amount + Cash-Out amount, excluding fees.
- Daily summary shows today's records; monthly summary uses the selected month; overall summary includes all records.
- The updated app keeps the existing localStorage key so prior records remain available in the same browser on the same phone.

IMPORTANT:
This is an independent record-keeping calculator. It does not connect to GCash, transfer funds, or verify payments. Records are stored locally in the browser and do not sync to other devices. Clearing browser/site data may erase records; keep a separate backup of important financial records.
